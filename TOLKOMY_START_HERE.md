# Только мы — Android (первый тест)

Основа: свободный клиент Element X Android (Matrix). Изменения находятся в отдельной ветке `feat/tolkomy-mobile-v1`; исходная ветка `develop` не изменена.

## Что изменено

- Название приложения на экране и в интерфейсе: **Только мы**.
- Отдельный Android application ID: `ru.tyanet.tolkomy`.
- Отдельная схема OAuth-переадресации: `ru.tyanet.tolkomy`.
- Одиночная тестовая сборка F-Droid Debug для ARM64 в GitHub Actions.

## Сборка только со смартфона

1. Откройте в браузере GitHub репозиторий `jkl09901/element-x-android`.
2. Перейдите в **Actions → APK Build → Run workflow**.
3. В списке **Use workflow from** выберите `feat/tolkomy-mobile-v1`, затем нажмите зелёную кнопку **Run workflow**.
4. Откройте завершившийся запуск и скачайте архив **TolkoMy-Fdroid-Debug-APK** в разделе **Artifacts**.
5. Распакуйте ZIP, затем установите находящийся внутри ARM64 APK на тестовый телефон.

При необходимости разрешите браузеру или файловому менеджеру установку приложений из этого источника.

Важно: это **тестовая debug-сборка**, а не финальная защищённая версия. Первичная сборка ещё не проверена. Не используйте её для настоящих конфиденциальных переписок, пока не настроены собственный Matrix-сервер, доставка push, безопасность входа и хранения, а также функция «Личное».

## Что пока не сделано

- Полноценный новый дизайн и иконка.
- Приватный раздел «Личное» и фотосейф.
- Сервер Matrix и вход только по приглашениям.
- Резервные копии, PIN, биометрия и проверенная настройка уведомлений.
